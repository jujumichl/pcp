Project Overview

The project was carried out by Titouan and myself. The code is accessible on GitHub: GitHub repository

Project Context

For this project, we were divided into groups. The objective was to build an Android application using React Native to manage internships, organisations, and contacts through a graphical interface.

Application Overview

Click on an image to enlarge it

This is the login page, which is the first page displayed when the application is opened. Authentication is handled by a REST API using token-based access, making it secure.

This is the first feature I implemented: displaying the user's email address in the application header. The second feature is visible in the bottom right corner of the screen; it adds the ability to log out, as there was no designated place for it.

This is the organisation detail page, which was handled by Titouan.

This is the internships page. We had to sort them by date, but it was not specified whether the order should be ascending or descending. I therefore sorted them in descending order by default, so that the most recent internships appear first. I then added a button to toggle the sort order between ascending order and descending order.

This is the internship detail page. I kept a layout similar to the organisation detail page, but added or removed elements that were not relevant. Since there were no specific requirements for internships, I took the initiative to create a skills table listing the competencies used during the selected internship.
