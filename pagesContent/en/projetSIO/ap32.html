Project Overview

Project Context

For this project, we were divided into groups. The objective was to build a Symfony REST API (Representational State Transfer) to manage internships, organisations, and contacts. An API is an interface that allows software systems to communicate with each other using the HTTP protocol. Through this API, in our context, we can create (POST) and retrieve (GET) an internship and a contact. We can also update and retrieve an organisation using routes.

API Overview

This is what a REST API looks like: there is no graphical interface and the result is presented in JSON. JSON is a format mainly used to store and transport data.

For simplicity, we will use a Google Chrome extension that makes it easier to send specific requests and configure them.
Talend is an extension that allows HTTP requests to be made. We can add what are called assertions: these allow us to verify the result of the request we sent. This way, we can run tests to confirm that our request returns the expected result.

The request shown above is a GET request. It allows us to retrieve all internships stored in our database, built with our ORM (Object Relational Mapper), which enables us to manage, manipulate, and retrieve data tables in the same way as objects, while keeping the PHP language. As there were only 2 of us in the group, we were unable to implement the API entry for contacts.
