Project Overview

The project was carried out by Titouan and myself. The code is accessible on GitHub: GitHub repository

Project Context

For this project, we were divided into 4 groups of 3. The objective was to build an application to manage users, projects, and groups on GitLab.

Since GitLab does not support bulk deletion, administrators must delete items one by one, which is time-consuming, particularly when removing multiple elements at once.
