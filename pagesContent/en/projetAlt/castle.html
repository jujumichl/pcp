Android Application Project for Fougères Castle

XAML • C# • Markdown

Number of people on the project: 1

Project Overview

The project was carried out by myself. The code is accessible on GitHub: GitHub repository

Origin and Client Need

The project originated from a request by Fougères Castle. They wanted an application that would allow visitors to watch French Sign Language presentation videos without an internet connection. Previously, they had a local website deployed on a tablet, which then required an internet connection to stream the videos — but the connection was unreliable. They therefore asked me to find a solution, and I proposed building an Android application.

Design Phase

A brainstorming session was held to define the features and design. This phase took place over one day. The client had no specific interface requirements; they simply wanted offline access to the videos and the ability to tap on the map.

Development

After researching how to build a mobile application, I chose to use C#. I started by setting up my first XAML page, then began developing the backend in C#. Below you will find the different pages of the application. You can click on the images to enlarge them.
