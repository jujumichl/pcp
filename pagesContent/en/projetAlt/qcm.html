Quiz (QCM) Website Project

PHP Symfony • Stimulus • Webpack Encore • MySQL • Twig • Markdown

UI Framework: Bootstrap • Number of people on the project: 2

Project Overview

The project was carried out by Owen and myself. The code is accessible on GitHub: GitHub repository

Origin and Client Need

The project originated from a request by Yasin, an IT department employee. He wanted a website that would allow users to create and take quizzes.

Design Phase

A brainstorming session was held to define the features and design. This phase took place over one week and resulted in an initial implementation of the user interface (UI).

You can click on the image to open it in your browser

Development – Authentication

Once the mockup was approved by Yasin, we began development. Authentication is linked to the Active Directory (AD), which means password hashing does not need to be managed. This part was implemented by Owen.

Development – Quiz Management Menu

While Owen was working on setting up the login page, I took charge of developing the side menu. The features requested by Yasin were:

Below, several screenshots illustrate how the menu works. You can click on them to enlarge them.

This is the home page for a new user. A message helps the user understand how to create a new quiz.

This is the quiz management menu, where the user can add, rename, and delete a quiz.

This is the interface when a user chooses to rename a quiz. As you can see, there is a rename confirmation button. It is also possible to confirm the rename with the Enter key and cancel it with the Escape key.

The message displayed is a rename confirmation message. It only appears when clicking on another rename action or when attempting to exit edit mode.

It is also possible to select all created quizzes and delete them all at once.

When attempting to delete a quiz, a confirmation message appears to prevent accidental deletions.

Once deleted, quizzes are moved to the trash and stamped with their deletion date. They are kept in the trash for 7 days and can therefore be recovered within the 7 days following deletion.

A selected quiz has a different style from unselected ones to differentiate them (the feature for taking a quiz is not yet developed at this stage).

This is the home page when the user has already created quizzes.

Quizzes can be accessed using a code: a 7-character hexadecimal number automatically generated when a quiz is created.

When clicking on a quiz to take it, a loading animation appears. This animation indicates to the user that the quiz is loading, improving the user experience by removing uncertainty during the loading process.

This is the quiz editing interface. All quiz fields can be modified (title, description, questions, answers, and correct answers). It is also possible to add and remove questions and answers. You can also choose the answer type for each question.

There are 3 different answer types for questions: single-choice answers, multiple-choice answers, and dropdown list answers. Dropdown answers can be selected from a drop-down list.

There is a save button for changes. When clicked, the changes are saved and a success message appears in the bottom right corner. If an error occurs while saving, an error message appears instead.

Quizzes can be configured to define an availability period. Once this period has passed, the quiz can no longer be taken.
