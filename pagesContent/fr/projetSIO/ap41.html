Présentation du projet

Le projet a été réalisé par Titouan ainsi que moi-même, le code est accessible sur GitHub : dépôt GitHub

Contexte du projet

Pour ce projet, nous avons été répartis en groupes. L’objectif était de réaliser une application Android sous React Native permettant de gérer des stages, des organisations et des contacts grâce à une interface graphique.

Présentation de l'application

Cliquez sur une image pour l’agrandir

Voici la page de connexion, c'est la première page sur laquelle on arrive quand on ouvre l'application. La connexion est gérée par une API REST et une authentification par jeton d'accès, elle est donc sécurisée.

Voici la première demande que j'ai réalisée, elle consistait à rendre visible l'adresse e-mail de l'utilisateur dans l'en-tête de l'application. La seconde est visible en bas à droite de l'écran, elle consistait à ajouter la possibilité de se déconnecter, nous n'avions pas d'emplacement précis pour l'ajouter.

Voici la page de détail d'une organisation, elle à été gérer par Titouan.

Voici la page des stages, nous devions les trier par dates, il n'était pas précisé si elle devait être triée dans l'ordre croissant ou décroissant. J'ai donc trié par défaut dans l'ordre décroissant afin d'avoir les stages les plus anciens d'abord. Ensuite j'ai ajouté un bouton pour trier les stages, soit dans l' ordre croissant soit dans l'ordre décroissant.

Voici la page de détail d'un stage, je suis resté dans un format identique à celui des détails d'une organisation, cependant j'ai ajouté ou supprimé des éléments qui ne m'étaient pas utiles. N'ayant pas de demande particulière concernant les stages je me suis donc permis de créer un tableau des compétences exploitées durant le stage sélectionné.
