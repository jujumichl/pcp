Projet d'application Android pour le château de Fougères

XAML • C# • Markdown

Nombre de personnes sur le projet : 1

Présentation du projet

Le projet a été réalisé par moi-même, le code est accessible sur GitHub : dépôt GitHub

Origine et besoin client

Le projet provient d’une demande du château de Fougères. Il souhaitait avoir une application quelconque qui permet sans connexion internet de consulter les vidéos de présentation en langue des signes française pour les personnes malentendantes, avant ils avaient un site web local à déployer sur tablette, puis ils devaient aller sur internet pour consulter les vidéos, sauf que la connexion internet n'est pas stable, ils m'ont donc demandé de trouver une solution, j'ai donc proposé de faire une application Android.

Phase de conception

Un brainstorming a été réalisé afin de définir les fonctionnalités et le design. Cette phase s’est déroulée sur une journée, la personne n'a pas demandé d'interface utilisateur particulière, elle souhaitait juste qu'on ait accès aux vidéos hors ligne et qu'on puisse cliquer sur la carte.

Développement

Après m'être documenté sur la façon de faire une application web, j'ai choisi d'utiliser le C#. J'ai donc commencé par mettre en place ma première page XAML puis j'ai commencé à faire le backend en C#, ci-dessous vous retrouverez les différentes pages de l'application.
