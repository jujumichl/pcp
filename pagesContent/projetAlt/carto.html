Projet de cartographie des travaux de Fougères

CSS • HTML • JavaScript • PostGreSQL • PostGIS • Markdown

Application web: Goeserver, mapstore • Nombre de personnes sur le projet : 1 puis 2

Présentation du projet

Le projet a été réalisé par moi-même, puis Owen m'a aidé sur le projet au début de son stage. Le code du script JS est accessible sur GitHub : dépôt GitHub

Origine et besoin client

Le projet provient d’une demande de la Mairie. La mairie souhaitait que les habitants puissent voir les travaux en cours et à venir dans la ville de Fougères, ainsi qu'avoir l'impact des travaux.

Phase de conception

Le projet avait déjà une première base avec une cartographie des travaux de Fougères faite, sauf que le projet n'était pas assez documenté, j'ai donc essayé de comprendre comment fonctionne le projet pour pouvoir y ajouter des modifications que Fabrice m'a demandées. Cependant le manque de documentation m'a obligé tout d'abord à reprendre le projet de zéros, ce que j'ai fait, je me suis donc renseigné sur les différents logiciels, et j'ai penser à trouver une façon de rendre stable la carte, j'ai donc pensé à créer une base de données qui allait contenir les données nécessaires à la cartographie.

Développement – Script de synchronisation API base de données

Le script de synchronisation de la base de données (BDD) avec l'Application Programming Interface (API) était le plus gros du travail, nous avions à gérer une connexion. Voici ci-dessous le site web mis en place pour publier la cartographie des travaux de la mairie de Fougères.

Explication de la structure du projet

Le projet est structuré sur 5 applications, tout d'abord l'API qui va nous permettre de récupérer les données, ensuite la base de données PostgreSQL/PostGIS qui va contenir les données de l'API et ainsi permettre à notre application d'avoir une stabilité, puis nous avons GeoServer qui va interpréter les données qui sont stockées en base de données, et MapStore qui va afficher les données interprétées par GeoServer, enfin nous avons notre interface web. Pour garder à jour notre base de données, nous avons dû faire un script de lancement automatique du script de synchronisation puis automatiser le lancement du lancement du script.
